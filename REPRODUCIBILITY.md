# Reproducibility

## Numerical and integrity checks

The required commands use Python's standard library only:

```sh
make verify
make verify-kappa
make reproduce
make composition
```

`make reproduce` recomputes four CSVs from the consolidated items, scopes, positive memberships and the unchanged category registry: `coverage.csv`, `category_support.csv`, `rq2_bubble.csv` and `axis_coverage.csv`. Generated bytes must match `results/reference/` before outputs are written. It checks group/manifestation identities, aliases, exact positive sets, category versions and same-item associations. It does not repair data or infer missing links.

`make verify` also checks the manifest, selection trace, 22 explanatory descriptions and composition. The manifest covers every distributed file except itself; it has no self-referential hash. Its external hash and the ZIP hash are recorded in the accompanying update report. Runtime caches, Python bytecode and explicitly generated figures are not original distribution members.

The record catalogue retains 243 selected/242 analytical/240 item-bearing bibliographic records. Consolidated counts are 242 selected/241 analytical/239 item-bearing groups, 1,554 items, 5,492 scopes and 3,700 memberships. The difference is the documented LC0173–LC0174 consolidation, not a publication exclusion. Source IDs and original aliases are retained.

## Historical agreement and composition

`make verify-kappa` uses only the preserved aggregate contingency matrix of the initial 12-record researcher–automated pilot: 11 agreements, expected agreement 85/144, and κ = 47/59. Reconciled labels are not used. See `METHODOLOGY.md` and `FULLTEXT_PILOT_AGREEMENT.md` for limitations.

`make composition` counts publication types and available page spans for 243 bibliographic records. It reports group denominators separately. A short page range, a document type or repeated technique description does not establish secondary-study status, quality or independence.

## Figures

For the standalone public diagrams, install Matplotlib in your chosen environment:

```sh
make figures-public
# or only Figures 3 and 6:
make figures-conceptual
```

The wrapper runs unchanged approved Python sources in a temporary package-local copy and writes to `results/generated_figures/`, leaving the packaged reference figures untouched. Figure 5 is an illustration of a source-reported assessment procedure, not a new sampled outcome. Dependencies used for validation are recorded in `requirements-figures.txt`; no quantum simulator is needed for these diagrams.

Figure 4's exact numerical cells reproduce with the standard-library commands. Full native rendering of Figures 1, 2, 4 and supplemental quantitative panels uses the corresponding approved manuscript source environment and assets; their original sources are retained here for provenance. The eleven original scientific PDFs remain in that separate source package. No standalone public regeneration or binary-PDF identity is claimed for those manuscript-dependent chains.

## Limits

This archive reproduces the approved aggregate synthesis. It does not re-execute historical licensed database searches, recover absent original human annotations, reclassify sources, establish checker effectiveness, infer family–level associations or approve RQ5 pairings. It contains no manuscript compilation target. The prior native SIGSEGV cause remains unverified; successful numerical commands do not resolve it. Historical release notes and DOI 10.5281/zenodo.24168011 refer to earlier bytes.
