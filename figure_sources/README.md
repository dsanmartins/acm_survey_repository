# Editable scientific figure source files

This directory contains available Python sources for the original scientific figures as well as editorial illustrations. The **11 previously validated scientific figures** remain in the separate manuscript ZIP; they are not redrawn or repackaged here.

## Current manuscript figure numbering

- **Figure 1** — original study selection design, preserved without changes. `study_selection_clean.py` can update reader-facing labels when supplied with the original source PDF and local rendering dependencies; the original PDF is in the manuscript ZIP.
- **Figure 3** — new RQ1 quality-phenomena conceptual map. Regenerated by `conceptual_maps.py`; approved PDF/PNG are included in `figures/`.
- **Figure 4** — RQ2 technique-family/analysis-mode evidence map. Numerical values are independently checked by `make reproduce` (see `results/reference/rq2_bubble.csv`).
- **Figure 5** — illustrative seven-field assurance-claim diagram with QASMInfer example. Regenerated by `assurance_reporting_schema.py` using Matplotlib; its output is in the manuscript ZIP. The displayed statistical verdicts are possible outcomes, not observations generated by this survey.
- **Figure 7** — conceptual comparison linking RQ3 representation, RQ4 condition, and RQ5 model-level implications. Regenerated by the **same** `conceptual_maps.py` script; approved PDF/PNG are included in `figures/`.

## Recreate the two new conceptual maps

Install Python 3 and Matplotlib (outside this package), then from the repository root run:

```bash
make figures-conceptual
```

The script writes `figures/rq1_concept_map.pdf` and `.png`, and `figures/rq3_rq4_rq5_bridge.pdf` and `.png`, using fixed PDF creation metadata for reproducibility. The maps are conceptual syntheses of the reviewed studies, not newly validated links, experimental findings, or common checker implementations.

Other Python scripts are retained for provenance and controlled scientific editing. Some need modules or historical analysis assets not supplied by this compact repository. These scripts are deliberately excluded from `make verify` and `make reproduce`; no Qiskit run is claimed or performed.
