# Existing category definitions and approved operational explanations

The registry contains 86 categories. For 22 existing categories the approved operational text below clarifies definition, inclusion and exclusion/interpretation limits. Other definitions are quoted from the unchanged registry; no missing criterion has been inferred. Technical IDs enable exact joins to the data and do not denote additional categories.
